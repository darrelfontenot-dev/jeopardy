    How it plays

    1. The host picks a clue for the player in control, reads it aloud, then presses Space to open the buzzers.
    2. First to ring in answers. The host marks it right (Y) or wrong (N). Wrong costs the clue value and the others can ring in.
    3. Daily Doubles let only the player in control wager. Double Jeopardy doubles every value.
    4. Final Jeopardy: secret wagers, one clue, answers revealed lowest score first.

    Tip: open the Host console from the in-game menu on a second screen or window so the answers stay private while you share the board.
